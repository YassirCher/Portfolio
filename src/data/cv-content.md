## ThinkGraph AI — completed PFE

ThinkGraph AI was Yassir's end-of-studies project from 1 April to 8 September 2026. It is a multimodal, multi-agent scientific research platform. It transforms text, figures, tables, formulas, and references in scientific PDFs into connected, queryable knowledge. Figure analysis supplies visual findings to LightRAG. Neo4j and Qdrant support hybrid graph, vector, and keyword retrieval using BGE-M3 embeddings. LangGraph agents handle prompt refinement, graph memory, retrieval, answer validation, citations, quizzes, reports, and presentations. The application uses FastAPI and Next.js, with Docker and Azure deployment work. The ThinkGraph source repository is private; access is available on request.

ThinkGraph presents 12 specialized agents and subagents across ingestion, research, and output: orchestrator, knowledge extraction, multimodal vision, table understanding, formula understanding, prompt refinement, graph memory, retrieval, validation, report synthesis, presentation, and quiz generation.

As part of the PFE, Yassir fine-tuned, compared, and evaluated 13 open-source LLMs on QASPER scientific question answering using QLoRA or LoRA. Phi-4-mini had the highest BERTScore F1 at 79.86% on 256 controlled examples. Public research repository: https://github.com/YassirCher/scientific-qa-llm-finetuning.
